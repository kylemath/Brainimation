\section*{Highlights}
\begin{itemize}
\item Browser-based coding tool for teaching EEG, optical PPG/fNIRS, and head motion.
\item Connects Muse 2016, Muse 2, Muse S, and Muse S Athena with no software install.
\item Built-in simulator lets students write and test code at home without hardware.
\item Visual Catalogue of \NCatalogueSketches\ example and student sketches across \NCatalogueCategories\ categories.
\item Evaluated on \NStudentSketches\ neurofeedback and ERP projects from \NUniqueStudents\ students ($p < 10^{-11}$).
\end{itemize}
