# Kyle E. Mathewson Academic Writing Style Guide
Summary:
1. Full Narrative Paragraphs Instead of Bullet or Numbered Lists. Eliminate `\begin{itemize}` and `\begin{enumerate}` in body sections. Use inline parenthetical numbering `(1) ...; (2) ...; and (3) ...` where needed.
2. Active, first-person plural voice ("We evaluate...", "We recorded...", "Our results demonstrate..."). Problem-to-solution pivots. Bridge engineering and physiology/cognition.
3. Plain-English narrative first; statistics, variable names, and code identifiers in parenthetical suffixes.
4. Typographic restraint and LaTeX hygiene: Avoid mid-sentence boldface clutter. Use non-breaking spaces before units and cross-references. En-dashes (`--`) for numeric ranges and coordinate compounds. Grammatically integrated equations. Self-contained captions.
5. Editing checklist: Zero body lists, plain-English flow, macro preservation, clean compile.
