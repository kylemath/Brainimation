# Clean Scientific Figures Skill
(Dumped copy for Worker 4)

## Core Rules
1. No Verbose Statistical Text Boxes or Callout Rectangles on Plots (NEVER ax.text/annotate with bbox containing stats).
2. Keep Legends Concise and Strictly Non-Overlapping:
   - Short series names only.
   - Corner placement without data overlap.
   - Add axis margin headroom (expand ylim/xlim by 15-25% so legend sits in whitespace).
3. Data-First Visual Hierarchy:
   - Maximize data-ink ratio.
   - Clean bold panel letters outside upper-left corner.
   - Concise panel titles.
