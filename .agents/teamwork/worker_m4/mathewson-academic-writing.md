# Kyle E. Mathewson Academic Writing Style Guide
(Dumped copy for Worker 4)

## 1. Full Narrative Paragraphs Instead of Bullet or Numbered Lists
- Eliminate \begin{itemize} and \begin{enumerate} in body sections.
- Unified multi-sentence paragraphs with ordinal or logical transitions.
- Run-in \paragraph{Title.} headings for distinct modules.
- Inline parenthetical numbering (1) ...; (2) ...; and (3) ...

## 2. Voice, Tone, and Narrative Momentum
- Active, first-person plural voice (We evaluate, We recorded, etc.).
- Problem-to-solution pivots.
- Bridge engineering and physiology/cognition.

## 3. Plain-English Narrative First; Statistics, Variable Names, and Code Identifiers in Parenthetical Suffixes
- Remove unnecessary variable names, filenames, and API identifiers from main clause.
- Place required statistics, variable/file names, and electrode labels in parenthetical suffixes.
- Leverage self-contained figure captions and tables.
- Deterministic macros over hardcoded numbers.

## 4. Typographic Restraint and LaTeX Hygiene
- Avoid mid-sentence boldface clutter (\textbf{...}). Reserve boldface for section/subsection titles, run-in \paragraph{...} headers, and table headers. Use \emph{...} sparingly.
- Clean LaTeX formatting: non-breaking spaces before units and refs, en-dashes for ranges, em-dashes for clauses.
- Self-contained captions.
