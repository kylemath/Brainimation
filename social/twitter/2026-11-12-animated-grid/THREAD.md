## 2

How Animated Grid listens.

Attention (beta 13–30 Hz + gamma 30+ Hz, averaged) sets wave speed. Theta (4–8 Hz) shifts hue. Alpha (8–12 Hz) lifts brightness. Meditation (alpha + theta, averaged) sizes each cell.

App scores from 0 to 1, not a clinical test.

## 3
